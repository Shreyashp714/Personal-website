# Shreyash Pandey — Personal Portfolio

Responsive one-page developer portfolio covering backend engineering, global payments, projects, and competitive programming.

Website address (once GitHub Pages is enabled): https://shreyashp714.github.io/Personal-website/

## Files
- `index.html` — complete website
- `Resume.pdf` — resume linked from the site
- `.nojekyll` — serves the site as plain static files on GitHub Pages

## Run locally
Open `index.html` in a modern browser.

## Deploy
### GitHub Pages
1. Push this folder to https://github.com/Shreyashp714/Personal-website.
2. Open the repository's Settings → Pages.
3. Under Build and deployment, select **Deploy from a branch**.
4. Select **main** and **/(root)**, then save.
5. Wait for the Pages deployment to finish, then visit the website address above.

Future pushes to `main` automatically update the website. No build step or dependencies are required.

### Netlify / Vercel
Deploy this folder as a static site.
